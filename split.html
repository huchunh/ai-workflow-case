Before automating anything, I decided who does what

The skill works because I split the job before automating it. This page shows the order I thought in: first whether the task could become a workflow at all, then which steps I keep, which AI runs alone, and which we share. Each assignment comes with the reason it is the right call.

What I thought about first

Is this a workflow at all?

Not every task should become a skill. Before I asked AI to automate anything, I checked the daily report against five questions. If most answers are yes, the task is a workflow: it can be written down once and run every day.

Does it repeat?
Every working day, same file, same steps.
YES
Is the input shape stable?
Same sheet layout daily: Port block A–H, City block I–O, ratios in percent format.
YES
Can the rules be written down?
Mostly. Delete, clear, flag, merge are rules. A few edge cases (rounding, exactly 0.15%) needed work to put into words.
AFTER WORK
Is the output fixed?
One cleaned xlsx and two images per port, same style, same folder naming.
YES
Can a result be checked quickly?
Yes, with counts of deleted and flagged cells, plus one look at an image.
YES
Becomes a workflow

Producing the daily report

Same input, same rules, same output. Every run should look identical to yesterday's except for the numbers.

Does not

Explaining why a port spiked

Different every time. Needs context about the port, the week, and the people involved. AI can help me think, but there is no fixed recipe to save.

The reasoning

What each side brings

Me

Context and accountability

  • Knowing why the report exists and who reads it
  • Knowing that people read the displayed 0.15%, not the stored 0.1493%
  • Deciding the process is ready to trust
  • Owning the daily report that gets sent
AI

Speed and consistency

  • Applies the same rule to every cell, every day
  • Never gets tired on row 200
  • Produces 12 images in one pass
  • Writes the process down as a reusable skill
Together

A tight feedback loop

  • AI shows results on real data; I react
  • During design, AI ran every rule on real files so I could judge it
  • My corrections become exact rules in the skill
  • At run time, one shared check before anything leaves

6
Why this split is correct

Why one image check is enough

An interviewer could fairly ask: if the flags matter so much, why not check them every day? Because the risk was handled at the right stage.

The rules were proven once

During design, the AI ran every rule on real files and I compared the result with what I would have done by hand, until they matched. Edge cases like 0.1493% and exactly 0.15% were found and written as exact rules then.

Code doesn't drift

The skill runs the same code on the same file layout every day. A rule that was right yesterday is right today. Re-checking every cell would repeat work the design phase already did.

The check sits where risk is highest

What can still go wrong day to day is the output: an image that renders badly or loses its red flags. One image check, right before sending, covers that. Sending stays with me, so nothing reaches the report without my look.

When I would change the split

The input changes

If the source file's layout, columns or threshold changes, the proven rules no longer apply. Then the affected steps move back to "together" until I've verified them on a real file again, and the skill is updated with a backup first.

What I deliberately don't do

Re-check every cell

That would make the automation pointless and add little safety, because a person scanning hundreds of cells is less reliable than the code that already checks them all.

Σ
What I take to the next workflow

Principles I now use

  • Ask "is it a workflow?" before "can AI do it?"

    If the input, rules and output are not stable, a saved skill will break. Keep it as a conversation instead.

  • Split by rule clarity and cost of a silent error

    Clear and cheap goes to AI. Clear but costly is shared, with a check built in. Judgment stays with me.

  • Check heavily while building, lightly while running

    Rules are verified on real data once. After that, one targeted check at the exit is enough.

  • My job in the shared zone is to name what's wrong exactly

    "Looks off" can't be automated. "Round half-up to two decimals, then compare with 0.15" can.

  • Keep anything sent to people with a person

    AI prepares the images; I complete the daily report and send it.

  • Make every change reversible

    Back up before updating the skill, so trying an improvement is never risky.
